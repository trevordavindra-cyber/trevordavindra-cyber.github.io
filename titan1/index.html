STACK
backend: FastAPI (Python) on CPU servers — controller API, task queues, auth, report engine
databases: PostgreSQL (agents, tasks, findings, audit records, permissions) + Redis (live agent state, task queues) + vector DB (historical findings, semantic search) + object storage (reports, evidence)
agents: 100 worker containers in Docker, one per agent identity, orchestrated by Kubernetes with health checks, auto-restart and horizontal scaling
message bus: broker between controller and agent containers with authenticated, encrypted messaging
model gateway: one shared gateway serving all agents — GPT / Claude / Gemini / Llama / Qwen / DeepSeek / local models, with fallback chains, rate limits, token and cost tracking
tools: the real binaries (nmap, burp, zap, nuclei, nessus, openvas, wireshark, zeek, suricata, yara, volatility, autopsy, prowler, trivy, checkov...) inside isolated sandbox containers, allowlisted targets only
monitoring: Prometheus + Grafana + OpenTelemetry + Wazuh for fleet health and security alerts
BOUNDARIES (unchanged from the browser edition)
per-agent identities and least-privilege permissions, target allowlists, human approval for sensitive actions, emergency shutdown, full audit logging, prompt-injection protection, no uncontrolled scanning, no destructive testing, no credential theft, no malware, no unauthorized access
MIGRATION PATH
this browser edition is phase 1: the controller logic, department structure, check menus, two-tier rule, findings schema and report format here are the same ones the server build uses, so the frontend and mission logic carry over and only the execution layer moves to containers
