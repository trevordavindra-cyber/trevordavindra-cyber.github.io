Prompt guide

How to type ideas that come out looking right the first time.

The formula

subject + style + lighting + color. "fiery dragon boss, 3D render, dramatic backlight, red and black" beats "dragon".

Asset types

Pick the right preset so the size and framing are right:

  • Game icon — one subject, centered. Roblox crops icon slots, so keep the subject in the middle third.
  • Thumbnail — wide 16:9 scene. Put your hero on the left, action on the right.
  • UI button / panel — say "flat UI design, straight-on view" so it doesn't render as a 3D scene.
  • Skill icon — tight crop, one object, glowing rim reads best at 48px.
  • Texture — use the texture recipes tab; they already say "seamless tileable".

Style reference

Upload a screenshot of UI you like. Forge pulls its five dominant colors and locks them into every generation, so a whole set matches. This is the fastest way to a consistent look.

Words that work

  • Composition: centered composition, rule of thirds, close-up, top-down
  • Light: golden hour, neon glow, rim light, volumetric fog
  • Mood: dark and moody, playful, epic, cozy, eerie
  • Roblox flavor: blocky character, voxel style, low poly

Words that hurt

Skip "high quality", "4k", "masterpiece" spam. One quality tier is already built in. Avoid asking for text in the image; models misspell, and Roblox overlays its own text anyway.

Seeds

Same prompt + same seed = same image. Found one you love? Note the seed (advanced options) and vary the prompt slightly to iterate on it. New seed = fresh variation.

Roblox upload rules

  • PNG or JPG, under 8 MB, longest side under 8000px. Every Forge preset already qualifies.
  • Game icons: 512×512. Thumbnails: 1280×720 or 1920×1080.
  • Upload via Roblox Studio Asset Manager, then use the asset ID in your ImageLabels.
